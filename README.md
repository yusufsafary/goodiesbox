# PromptPlay

> what kind of prompter are you?

PromptPlay analyzes your AI prompting habits and prints them as a receipt. Paste your prompts, get your archetype, share the roast.

## Live Demo

[promptplay.vercel.app](https://promptplay.vercel.app)

## Features

- **8 Archetypes** — Vibe Coder, Context Hoarder, Micromanager, Lazy Genius, Overthinker, Serial Prompter, Philosopher, Debugger
- **Beta Testnet** — Paste prompts, get your receipt instantly, all in-browser
- **Interactive receipt** — Styled like a real receipt with stats and a personalized roast
- **Leaderboard** — See the top prompters ranked by chaos
- **Mobile first** — Built for thumbs

## Stack

- React 18 + Vite
- Tailwind CSS
- React Router
- Lucide icons
- No backend required during beta

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Deploy to Vercel in one click. All analysis runs in the browser, no env vars required.
